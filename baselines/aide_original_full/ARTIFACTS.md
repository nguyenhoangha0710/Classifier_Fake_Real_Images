# AIDE original Full artifacts

- `artifacts/checkpoints/`: checkpoint canonical và metadata kiến trúc/train.
- `artifacts/checkpoints/archive/check_point.rar`: bản archive checkpoint cũ.
- `artifacts/runs/aide_original_full_tiny_commfor/`: output train AIDE gốc full.
- `artifacts/evaluations/commfor_unseen/`: metrics và predictions CommFor.
- `artifacts/runtime_snapshot/`: snapshot runtime đi kèm output gốc.
- `artifacts/notebook_outputs/`: notebook đã chạy, chỉ dùng làm bằng chứng lịch sử.

Checkpoint trong thư mục này thuộc **AIDE gốc Full** (semantic OpenCLIP +
forensic DCT/SRM), không thuộc biến thể AIDE + NPR.
